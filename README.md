# NEBULA

Клиентский Roblox-хаб: визуальные эффекты, HUD и собственные игровые модули. Текущий релиз — **6.9**, Control — **1.12**.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/6ixl/nebula-visuals/main/main.lua"))()
```

Нужен исполнитель с `loadstring` и `game:HttpGet`. Вставь строку в его редактор и выполни. Ссылка выше получает текущую версию ветки `main`.

Фиксированный релиз 6.9:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/6ixl/nebula-visuals/v6.9/main.lua"))()
```

## Обновление 6.9

Фото: размер клетки **0.1–6 studs**. Клетка 0.1 уменьшает картину 200×200 до 20×20 studs; пикселей и нужных блоков остаётся столько же. Исправлены оба валидатора и слишком широкий допуск проверки размера. Нужен обновлённый [HTML-импортер](https://github.com/6ixl/nebula-visuals/releases/download/v6.9/NEBULA-Photo-Importer.html).

Гараж: новые отдельные профили кузова/кабины по фотографиям, многосекционные поверхности, индивидуальные фары/впуски/фонари. Это приближения по фото, **не копии 1:1**. [Изменения и проверки](docs/UPDATE-6.9.ru.md), [референсы](docs/CAR-REFERENCES.md).

## Гараж: 10 спорткаров · экспериментально

Новая кнопка **«NEBULA Garage · 10 спорткаров»** в Хабе. Собственные схемы по мотивам McLaren, Ferrari, Lamborghini, Porsche, Bugatti, Koenigsegg и Nissan: 1132–1252 блока, цвет кузова, 3D-превью, список материалов, 4 колеса, 4 пружины, 16 рычагов и профили подвески. Требуются свои блоки и игровые инструменты.

**Реальная сборка и езда в BABFT не проверены.** Это блоковые интерпретации, не точные реалистичные копии. Адаптер пытается собрать и связать механику через инструменты; после постройки сохраняет закрепление. Аудит соединений предшествует отдельной команде снятия закрепления и не гарантирует рабочую езду. [Инструкция и ограничения](docs/GARAGE.ru.md).

![Офлайн-рендер схем гаража, не игровой снимок](https://github.com/6ixl/nebula-visuals/releases/download/v6.9/NEBULA-Garage-Contact-Sheet.png)

## Фото в Build a Boat: 200 пикселей и ×10

Обновлённый [HTML-импортер из релиза](https://github.com/6ixl/nebula-visuals/releases/download/v6.9/NEBULA-Photo-Importer.html) поддерживает до **200×200** клеток, сохраняет пропорции и принимает до **40 000** точек. Каждый непрозрачный пиксель требует имеющийся блок. Значение по умолчанию — 24.

В своём Boat-модуле появился ползунок **«Скорость постройки фото · ×1–×10»**, доступный и во время постройки. ×10 уменьшает минимальные интервалы запросов с 0.5 до 0.05 секунды; подтверждения размещения/размера/цвета и один ожидающий запрос сохраняются. Реальная скорость зависит от сервера; десятикратный результат не гарантируется.

Большой JSON может обрезаться текстовым полем игры. Используй **«Скопировать Lua импорта»** в HTML и выполни этот код при уже запущенной NEBULA 6.7. Также есть импорт из буфера (если доступен getclipboard) и `<имя>.json` из рабочей папки исполнителя. Ничего из JSON не исполняется как Lua. Для больших картин локальное превью упрощено до 4096 объектов; настоящая схема остаётся полной.

## Что внутри

- **Visuals:** чёрный интерфейс, поиск, погода, туман, освещение, эффекты персонажа, HUD, шрифты и настройка окна.
- **Control:** 114 команд, 2D/3D/угловой ESP с ником и HP, перемещение, личные точки, сценарии с повторами, общий сброс и KILL.
- **Свои модули:** Build a Boat, MM2, Violence District, Spray Paint, DOORS и Tower of Hell.
- **MM2 Aim:** плавное наведение при экипированном Gun, FOV, удержание кнопки, проверка видимости и упреждение. Автоматической стрельбы в aim-модуле нет.
- **Spray Paint:** фото по HTTPS-ссылке, область из трёх кликов, 23 картинки в интернет-галерее, фильтры, поворот, отражение, порядок штрихов, пауза, продолжение и JSON-проекты.
- **Build a Boat:** проход найденных этапов, собственная база и пробная постройка фото игровыми инструментами.

Горячие клавиши по умолчанию: **RightShift** — Visuals, **RightAlt** — Control, **F9** — Silent интерфейса, **F6/F7/F8** — fly/noclip/ESP. Бинд меню меняется в настройках. Функции включаются вручную; KILL выгружает собственные модули.

## Фото и Spray Paint

1. Скачай **NEBULA-Image-Helper.exe** из [релиза 6.7](https://github.com/6ixl/nebula-visuals/releases/tag/v6.7) и запусти вручную.
2. Открой **Хаб → NEBULA Spray Paint · свой скрипт**. Вставь прямую HTTPS-ссылку на изображение либо выбери картинку в галерее.
3. Выбери область: верхний левый → верхний правый → нижний левый угол одной плоской детали. **Escape** отменяет выбор.
4. Проверь локальное превью, экипируй SprayPaint и включи рисование. Есть пауза и стоп.

Помощник декодирует изображения на твоём ПК и слушает только `127.0.0.1:8766`. Его исходник — [tools/image-helper.py](tools/image-helper.py). Для запуска из исходника нужны Python 3.12+ и Pillow:

```powershell
python -m pip install -r tools/requirements.txt
python tools/image-helper.py
```

Для картин из блоков Boat есть [локальный HTML-импортер](tools/photo-importer.html). Скачай и открой его в браузере; он работает с локальным файлом фото.

## Проверки и ограничения

Код компилировался Luau 0.745. Модельные проверки покрывают переключатели, сценарии, отмену, ESP/aim, обработку схем, игровые структуры и KILL. Декодер проверялся настоящей загрузкой PNG и запуском собранного Windows EXE.

**В Roblox/Solara новые игровые функции не проверены.** Модельные тесты не подтверждают серверную отрисовку, попадания, награды, победы или сбор. Игровые структуры и протоколы могут меняться. Нет гарантированных godmode, автопобеды, невидимости от ESP, точности фото «1 в 1» или обхода античита. RTX-пункт — пресет освещения, а не трассировка лучей.

Silent скрывает интерфейс локально. Локальные визуальные эффекты не становятся видимыми другим игрокам. Уже отправленные серверу действия, размещённые блоки и штрихи не отменяются простой выгрузкой клиента.

В Хабе также есть **отдельный каталог сторонних скриптов**. Они выполняются только по нажатию, могут загружать собственные зависимости и имеют собственную остановку. Общий KILL NEBULA не гарантирует их выгрузку.
