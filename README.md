# NEBULA 6.11 preview

Roblox visual hub, Control and experimental Build a Boat garage.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/6ixl/nebula-visuals/main/main.lua"))()
```

Вставь строку в Solara и нажми Execute после обновления исполнителя. New-модели скачиваются как JSON из этого выпуска; отдельно устанавливать файлы не требуется.

## Обновление 6.11

- Legacy / New: десять новых геометрий машин и Abrams с интерьером.
- Выбор моделей списком с поиском; таблица материалов и расчёт запаса по объёму.
- Прогресс сборки, прошедшее/оставшееся время, пауза и ползунок ×1–×500. Множитель уменьшает задержки скрипта; скорость сервера он не увеличивает в 500 раз.
- Переработаны стёкла, положение механизмов колёс и кресла, отдельная внешняя геометрия без коллизии. Игровые механизмы скрываются PropertiesTool.
- Настройка колёс, настоящие Spring/Bar и длина по Attachment; строгая проверка соединений перед запуском.
- Отдельные KILL-кнопки убраны. Крестик полностью закрывает хаб и Control; бинд только скрывает окно. Построенные серверные блоки сохраняются.

**Это preview:** игровые проверки обновлённой геометрии, подвески, гусениц, башни и стрельбы отложены по просьбе пользователя. Компиляция не подтверждает их работу. Су-57 в этот выпуск ещё не включён, он разрабатывается отдельно.

Изменения применяются при новой сборке; готовые старые постройки автоматически не переделываются. Техника является блоковым приближением, не точной CAD-копией.

Авторы и лицензии новых 3D-основ: [THIRD-PARTY-MODELS.md](THIRD-PARTY-MODELS.md). Описание прошлых функций: [docs/GUIDE.ru.md](docs/GUIDE.ru.md).
