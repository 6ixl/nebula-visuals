- Lua-модель Roblox: ESP, aim, сценарии, повтор/возрождение, остановка, GUI-состояния, отдельные модули, галерея/обработка/проекты, порядок/продолжение штрихов, серверные вызовы через подставные RemoteEvent/RemoteFunction — проверки прошли.

- Реальный Roblox/Solara: игровой runtime, совместимость актуальных карт, сетевая репликация, попадания/урон, награды, отрисовка и очистка сторонних скриптов НЕ ПРОВЕРЕНЫ.

Модельные результаты не равны проверке в игре. Метаданные сохранены из локального релизного набора; исторические имена файлов в них относятся к первоначальным артефактам, а не к текущим путям репозитория.

Для проверки синтаксиса нужен официальный luau-compile из [Luau](https://github.com/luau-lang/luau):

```powershell
luau-compile --null main.lua
luau-compile --null control.lua
luau-compile --null games/mm2.lua
```
