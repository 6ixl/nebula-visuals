Модельные результаты не равны проверке в игре. Метаданные сохранены из локального релизного набора; исторические имена файлов в них относятся к первоначальным артефактам, а не к текущим путям репозитория.

Для проверки синтаксиса нужен официальный luau-compile из [Luau](https://github.com/luau-lang/luau):

```powershell
luau-compile --null main.lua
luau-compile --null control.lua
luau-compile --null games/mm2.lua
```
