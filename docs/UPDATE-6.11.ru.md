# NEBULA 6.11 preview 3 — привязка колёс

- Все машины: явная привязка Forward=W, Backward=S, Left=A, Right=D через штатный BindTool в режиме SeatInput.
- После команды проверяются назначенные клавиши и связь каждого из четырёх колёс с креслом.
- Кнопка «Исправить привязку колёс · W/S/A/D» для готовой своей машины. После перезапуска нужен один CarSeat в радиусе 20 studs и ровно четыре колеса в 22 studs от него. При неоднозначности команда не отправляется.
- Кнопка меняет только привязку; она не снимает закрепление и не исправляет повреждённые соединения.

Офлайн-проверки команды и компиляция прошли. Реальная езда и поворот в Roblox этой версией пока не проверены.
